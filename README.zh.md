# 家电行业：回归、神经网络与ARIMA建模
**[English](./README.md) | 中文**

本项目为 **第10届全国大学生统计建模大赛（上海赛区二等奖）** 的统计建模项目。项目运用回归分析与神经网络模型对中国家电行业的发展水平进行深入剖析，并利用 ARIMA 模型对未来趋势进行预测。

## 项目概述

本项目提出了一种针对中国家电行业经济增长的测度方法，并进行了实证检验。项目包含三个核心建模部分：

1. **描述性分析**：指标选取、测度方法选择，以及对清洗后数据的描述性统计。
2. **回归与神经网络拟合**：将两种模型拟合至指标数据，以考察国内外需求如何驱动行业发展。
3. **ARIMA 预测**：构建时间序列模型，预测未来五期的数据，以评估未来发展趋势。

**核心结论**：内需是驱动销量增长的主要动力，且内需增速已超过外需。这促使行业向着合理的库存水平迈进，改善了产销协调性，整体呈现出平稳向好的态势。产品创新与市场拓展被确定为未来增长的主要方向。

## 我的贡献

本人主要负责**回归分析与 ARIMA 预测部分**：

- 从 30,000 多条原始记录中筛选出 3,000 条有效观测值并进行数据清洗。
- 使用 SPSS 进行描述性统计分析。
- 构建并比较了多元线性回归模型，对销量、产量及库存的拟合模型进行了解读。
- 应用 ARIMA 模型对未来五期进行预测，并分析了未来的发展趋势。

*注：神经网络拟合部分由团队协作完成，本人参与了解读所有模型的综合结果。*

## 代码说明

- `matlab/feedforward-net-fitting.m`：前馈神经网络拟合（冰箱数据），MATLAB `fitnet`。
- `matlab/narx-time-series-forecast.m`：NARX 非线性自回归网络用于时间序列预测（空调数据），MATLAB `narxnet`。

*注：上述两个 MATLAB 脚本摘自竞赛论文，属于团队的神经网络建模部分。本人的回归分析与 ARIMA 预测是通过 SPSS 图形界面完成的，无独立脚本文件；模型摘要图表已记录了拟合的具体规格。*
